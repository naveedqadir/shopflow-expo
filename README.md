# ShopFlow

ShopFlow is a modern, beautifully designed e-commerce application built with Expo and React Native.

## Features
- **Dynamic Theming:** Full support for Light and Dark modes.
- **State Management:** Zustand for client state, TanStack Query for server state.
- **Navigation:** File-based routing with Expo Router.
- **Animations:** Smooth interactions with Reanimated and Gesture Handler.
- **Styling:** Custom, premium UI design.
- **Mock Data:** Ready-to-use mock API with realistic e-commerce scenarios.

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm start
   ```

3. **Run on iOS/Android:**
   - Press `i` to open in iOS simulator
   - Press `a` to open in Android emulator
   - Press `s` to switch to Expo Go

## Tech Stack
- Expo SDK 56
- React Native
- React Hook Form + Zod
- Zustand + TanStack Query
- Lucide React Native (Icons)
